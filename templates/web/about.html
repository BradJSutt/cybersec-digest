The pipeline

How an issue is made

01

Collect

A scheduled job pulls the latest entries from every configured RSS and Atom feed, dropping anything older than the lookback window and de-duplicating by URL.

02

Curate

Each story is summarised from its own page, classified into a section, and ranked. Critical and actively exploited vulnerabilities always surface first.

03

Publish

The same curated dataset renders two ways: a print-ready weekly PDF and this web edition. No shadow copies, no drift between formats.

What's inside

Eleven sections, one scan.

Stories are grouped so you can read top-down or jump straight to what you care about. Articles that fit multiple sections land in the highest-priority one.

Privacy

Local, private, no tracking pixels.

This site runs on a local server. Subscriber addresses are stored in a single SQLite file and are only used for digest delivery. Link clicks are counted in aggregate to understand which sections readers value — never tied to a person.

No third-party analytics, no advertising, no data resale.

Questions

FAQ

How often is it published?

Once a week. The scheduler runs Monday morning by default; the exact day and time live in config.yaml.

Can I suggest a feed?

Yes — feeds are plain YAML entries. Add a name, URL and category, then the next run picks it up automatically.

Is there a cost?

No. The digest is an internal project built for the networking team and released as open-source boilerplate.

How do I unsubscribe?

Use the unsubscribe form on the subscribe page. It removes you immediately.
